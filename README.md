# HpSA 糞便抗原檢驗申報系統 (HpSA Screening System) v1.0.0

## 關於本系統
本系統專為糞便抗原檢驗申報業務設計，提供檢驗紀錄的數位化管理、報告列印、以及健保申報資料匯出等功能。版本 v1.0.0 為正式發行版，包含完整的檢驗流程管理與系統設定功能。

## 主要功能

### 1. 檢驗紀錄管理 (Dashbaord)
進入系統後的主要工作區域 (`檢驗紀錄管理` 分頁)，提供以下功能：

#### 🔍 搜尋與篩選
- **基礎搜尋**：可直接輸入「姓名」、「身分證字號」或「院所名稱」進行快速檢索。
- **日期範圍**：設定「檢驗日期」區間來篩選資料。
- **進階搜尋**：點擊「進階搜尋」按鈕，可針對更多欄位（如檢驗單號、出生日期、列印/匯出狀態等）進行精確查找。
- **操作按鈕**：
  - `查詢`：執行搜尋條件。
  - `清除`：重置所有搜尋條件與篩選器。

#### 📋 列表操作
- **新增紀錄**：點擊右上角的 `+ 新增紀錄` 按鈕開設新資料。
- **編輯/刪除**：在列表中針對單筆資料點擊 `編輯` (筆圖示) 或 `刪除` (垃圾桶圖示)。
- **狀態標示**：列表清楚標示每筆資料的 `待申報` (灰色)、`已匯出` (藍色) 或 `已刪除` (紅色) 狀態。

#### 🖨️ 列印與匯出
- **列印報告**：
  - **單選列印**：選取列表左側的核取方塊 (Checkbox)，點擊上方的 `列印選取` 按鈕。
  - **個別列印**：在單筆資料的操作欄位點擊 `列印` 圖示，可選擇列印「第一張」、「第二張」或「兩張都印」。
- **資料匯出**：
  - **匯出選取**：勾選資料後，點擊 `匯出選取`，系統將生成健保申報格式的 Excel 檔案。
  - **匯出欲刪除資料**：針對標記為「已匯出」的資料，可選擇匯出刪除清單。

### 2. 系統設定 (Settings)
點擊左側導覽列的 `系統設定與維護` 進入設定頁面：

- **院所管理**：管理合作的醫療院所資料 (代碼、名稱)，方便建檔時快速選取。
- **預設值設定**：
  - **資料庫路徑**：檢視或修改資料庫檔案 (`hpsa.db`) 的存放位置。若修改路徑，需重啟應用程式生效。
  - **備份功能**：一鍵備份當前資料庫。

## 系統需求
- **作業系統**：Windows 10 / 11 (64-bit)
- **其他需求**：需安裝 PDF 閱讀器以檢視列印報告。

## 常見問題 (FAQ)
- **Q: 資料庫路徑可以更改嗎？**
  - A: 可以。請至「系統設定 > 預設值設定」中修改，修改後請務必重新啟動程式。
- **Q: 匯出的 Excel 檔案無法開啟？**
  - A: 請確認您的電腦已安裝 Excel 或相容的試算表軟體，並確保匯出時該檔案未被其他程式開啟。
