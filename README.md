# HpSA 糞便抗原檢驗申報系統 (HpSA Screening System) v1.2.0

## 關於本系統
本系統專為糞便抗原檢驗申報業務設計，提供檢驗紀錄的數位化管理、報告列印、以及健保申報資料匯出等功能。版本 v1.2.0 新增半張 A4 管理紀錄表與列印開關，並保留資料庫備份還原、CSV 匯出及費用對帳單功能。

## 主要功能

### 1. 檢驗紀錄管理 (Dashboard)
進入系統後的主要工作區域 (`檢驗紀錄管理` 分頁)，提供以下功能：

#### 🔍 搜尋與篩選
- **基礎搜尋**：可直接輸入「姓名」、「身分證字號」或「院所名稱」進行快速檢索。
- **日期範圍**：設定「檢驗日期」區間來篩選資料。
- **進階搜尋**：點擊「進階搜尋」按鈕，可針對更多欄位（如檢驗單號、出生日期、列印/匯出狀態等）進行精確查找。
- **操作按鈕**：
  - `查詢`：執行搜尋條件。
  - `清除`：重置所有搜尋條件與篩選器。

#### 📋 列表操作
- **新增紀錄**：點擊右上角的 `+ 新增紀錄` 按鈕開設新資料。
- **編輯/刪除**：在列表中針對單筆資料點擊 `編輯` (筆圖示) 或 `刪除` (垃圾桶圖示)。
- **狀態標示**：列表清楚標示每筆資料的 `待申報` (灰色)、`已匯出` (藍色) 或 `已刪除` (紅色) 狀態。

#### 🖨️ 列印與匯出
- **管理紀錄表**：單筆與批次列印時，每筆紀錄會在原檢驗報告後附加「糞便抗原檢測胃幽門螺旋桿菌服務」管理紀錄表，版面為橫式半張 A4（210 × 148.5 mm），放在獨立 A4 頁面的上半部。請使用 A4 直向、100% 比例並關閉瀏覽器頁首頁尾。
  - 可於「系統設定與維護 > 預設值設定」切換「列印時一併印出管理紀錄表」，並儲存設定。預設開啟；關閉時僅列印原報告，重新啟動後仍保留設定。
  - 同一張表呈現第一次及第二次檢驗資料；原報告的第一次／第二次／全部列印選擇仍保留。
  - 院所、姓名、身分證字號、民國日期與檢驗結果由紀錄帶入，檢驗機構名稱由系統設定帶入。
  - 試劑名稱與許可證字號依試劑代碼帶入；代碼 999 使用紀錄中的自訂資料。未提供的有效期限留白，供確認後填寫。
- **列印報告**：
  - **批次列印**：選取列表左側的核取方塊 (Checkbox)，點擊選取工具列的 `列印選取` 按鈕。若選取資料包含二次檢驗結果，可選擇第一次、第二次或全部報告。
  - **個別列印**：在單筆資料的操作欄位點擊 `列印` 圖示，可選擇列印「第一張」、「第二張」或「兩張都印」。
- **資料匯出**：
  - **匯出選取**：勾選資料後，點擊 `匯出選取`，系統支援生成 Big5 編碼的 CSV 申報檔案。
  - **匯出欲刪除資料**：針對標記為「已匯出」的資料，可選擇匯出刪除清單。

### 2. 費用對帳單 (Billing)
點擊左側導覽列的 `費用對帳單` 進入對帳單管理頁面：
- **產生對帳單**：輸入檢驗診所名稱、日期範圍、每支試管預扣費用，即可生成對帳單。
- **對帳單功能**：
  - 自動計算總檢驗次數與總金額。
  - 支援列印與轉存 PDF。

### 3. 系統設定 (Settings)
點擊左側導覽列的 `系統設定與維護` 進入設定頁面：

- **院所管理**：管理合作的醫療院所資料 (代碼、名稱)，方便建檔時快速選取。
- **預設值設定**：
  - **資料庫路徑**：檢視或修改資料庫檔案 (`hpsa.db`) 的存放位置。若修改路徑，需重啟應用程式生效。
  - **備份功能**：一鍵備份當前資料庫 (`.db`)。
  - **還原功能**：可選取備份檔還原資料庫（還原後需重啟應用程式）。

### 4. 開發者工具 (Dev Only)
- **Mock Data**：僅在開發模式下顯示。可生成 100 筆符合台灣身分證字號規則的測試資料，並具備條件式檢驗結果邏輯。
- **Clear All**：一鍵清除所有檢驗紀錄（需再次確認）。

## 系統需求
- **作業系統**：Windows 10 / 11 (64-bit)
- **其他需求**：需安裝 PDF 閱讀器以檢視列印報告。

## 常見問題 (FAQ)
- **Q: 資料庫路徑可以更改嗎？**
  - A: 可以。請至「系統設定 > 預設值設定」中修改，修改後請務必重新啟動程式。
- **Q: 如何開啟匯出的 CSV 檔案？**
  - A: 可使用 Excel 或相容的試算表軟體匯入；若中文顯示亂碼，請指定 Big5 編碼。匯出前請確認目標檔案未被其他程式開啟。
